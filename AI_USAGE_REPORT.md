Отчет по использованию ИИ в игре
Отчёт об использовании ИИ и инструментов (Разработка кода)
1. Перечень использованных инструментов и моделей:
   В процессе разработки использовались нейросети (ИИ-ассистенты) для генерации и оптимизации кода, а также следующие инструменты и библиотеки:
   CometRenderer (автор: Ferra13671, лицензия: Eclipse Public License 2.0) — база для рендера, включая используемые в проекте авторские дополнения (better-compiler, glfw и куски кода из crm).
   Overtone (автор: Ferra13671, лицензия: Eclipse Public License 2.0) — звуковой движок.
   LWJGL (https://github.com/LWJGL/lwjgl3) — лицензия BSD-3-Clause.
   json-utils (автор: Ferra13671, лицензия: MIT) — библиотека для парсинга json файлов.
   json5-java (https://github.com/marhali/json5-java) — лицензия Apache-2.0.
2. Зоны применения ИИ (какие задачи решал):
   ИИ применялся для написания и отладки кода следующих механик:
   Обработка столкновений со стенами и сущностями.
   Процедурная генерация уровней (расстановка комнат и генерация коридоров между ними).
   Поведение ИИ мобов и боссов, а также их спавн в подземелье.
   Рендер HUD и создание меню.
   Быстрый поиск багов и написание фиксов.
   Другие мелкие рутинные задачи.
3. Пример эффективного приёма:
   ИИ сильно ускорил разработку, позволив делегировать рутинные задачи и сконцентрироваться на структуре и механиках игры.
   Пример эффективного приема: Написание продуманного поведения боссов и врагов с помощью детальных промтов.
4. Что сделано без ИИ:
   Проектирование общей архитектуры игры, игровой цикл (game loop), ручная интеграция собственных движковых библиотек (CometRenderer, Overtone, json-utils), а также ручная отладка сложных взаимодействий между системами.
   5.При помощи chat GPT были сделаны спрайты главных героев, врагов, комиксы,
   заставка в главном меню, магазин. Так же с его помощью были пересованы модельки оружия главных героев. Изначальные модели оружия взяты из открытых источников.
   Анимации передвижения, атак и т.д. были сделана при мощи нейросети Claude
   Текстуры окружения взяты из открытых источников
