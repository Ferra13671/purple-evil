# PurpleEvil Assets

**Platform:** Executable

---

## 1. Made by the team
| Category            | Location                                                                                                        | Description                                                                                                                                                                                                                                                                                                                               |
|---------------------|-----------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Game code           | `src/main/java`, `build.gradle`                                                                                 | Project architecture, gameplay core (controls, combat system), camera, implementation of custom engine libraries (CometRenderer with add-ons, Overtone, json-utils), manual integration and adaptation of AI-generated code (collisions, generation, mob AI, UI). Also, the code for packaging the .jar file into a monolithic .exe file. |
| Data                | `src/main/resources/assets/attributes`, `src/main/resources/assets/upgrade`, `src/main/resources/assets/world`  | Data on entity attributes, upgrades, and room structures.                                                                                                                                                                                                                                                                                 |
| Shaders             | `src/main/resources/assets/shaders`                                                                             | Shaders used in the game.                                                                                                                                                                                                                                                                                                                 |
| Player damage sound | `src/main/resources/assets/sounds/damage/player.ogg`                                                            | Original damage sound.                                                                                                                                                                                                                                                                                                                    |
